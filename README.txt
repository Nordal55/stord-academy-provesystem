STORD ACADEMY – PRØVESYSTEM PROTOTYPE 8 – NETTVERSJON

Dette er første Supabase-versjon basert på Prototype 7.
- Lærling starter prøve på nett og får unik tilgangskode.
- Svar autosaves til Supabase.
- Lærlingen kan fortsette fra annen PC med tilgangskoden.
- Levering låser prøven.
- Instruktørdelen bruker Supabase Auth og krever godkjent instruktørkonto.
- Instruktør kan rette, kommentere og publisere resultat.
- Lærling kan se publisert resultat med tilgangskoden.

FØR OPPLASTING TIL GITHUB:
1. Kjør SUPABASE_SQL_STEG_3.sql i Supabase SQL Editor.
2. Last opp/erstatt index.html på GitHub sammen med de eksisterende vedleggsfilene.
3. Opprett instruktørkonto fra Instruktør-siden i appen.
4. Godkjenn kontoen i Supabase med SQL (se veiledning fra ChatGPT). Ikke legg service_role/secret key i GitHub.

Dette er fortsatt en pilot. Test med en testbruker før ekte prøve.
